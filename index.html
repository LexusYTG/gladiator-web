Información

Nombre Gladiator Paquete com.glads1 Licencia MIT Plataforma Android arm64

Gladiator es un APK Android que empaqueta un entorno Linux de escritorio completo. Se instala, se abre, y tenés una sesión X11 con JWM y un escritorio propio (Sesar) corriendo dentro de un container Ubuntu, con aceleración gráfica real del hardware del dispositivo.

No requiere Termux instalado, ni root, ni un servidor X externo. Todo está adentro del APK: el host bionic, el container glibc, el servidor X embebido, los shims de GPU y el audio. El usuario instala y usa.

Identidad

Gladiator no traduce. Expone. Los shims (Scutum para GLES, Spatha para Vulkan) reenvían cada llamada al driver oficial de la GPU, sin capas de emulación intermedias. La aplicación ve la GPU nativa como si fuera suya. La latencia de un round-trip por socket es lo único que paga el usuario; a cambio recibe el driver propietario sin alteraciones.

Componentes

  • Scutum — puente GLES/EGL bionic↔glibc. Da a las apps del container acceso directo al driver OpenGL ES del dispositivo.
  • Spatha — puente Vulkan bionic↔glibc. Expone el driver Vulkan del sistema como un ICD de escritorio.
  • Sesar — entorno de escritorio en C puro sobre Xlib y FreeType. Sin toolkits. Sin GTK ni Qt.
  • Lorica — capa de traducción OpenGL 3.1 core sobre GLES 3.0+. Para apps modernas que ya no usan el modo de función fija.
  • Orator — puente PCM entre PulseAudio del container y el audio del dispositivo.

Qué promete

  • Un escritorio Linux usable en Android, sin root, sin advertencias de seguridad rotas, sin herramientas externas.
  • Aceleración gráfica real vía driver propietario, no por traducción a Vulkan ni emulación por software.
  • Un stack de código propio, mantenible, en C y C++.
  • Audio funcional con PulseAudio sobre OpenSL ES.
  • Instalación limpia, sin configuración manual del entorno.

Qué no promete

  • Correr todo juego de Windows. Eso requiere Wine + Box64 + DXVK, otro proyecto.
  • Rendimiento idéntico al nativo. La latencia del puente y la traducción del software pesan, aunque cada release la reduce.
  • Compatibilidad universal. El hardware primario es Mali-G52 MC2 con driver ARM propietario. Otros GPUs no están testeados.
